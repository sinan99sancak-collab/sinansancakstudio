SINAN SANCAK WEBSITE
====================
Bu paket statik, hızlı bir başlangıç sitesidir.

Dosyalar:
- index.html
- style.css
- script.js

Fotoğraf alanlarındaki placeholder kutularını kendi fotoğraflarınla değiştirebilirsin.
İletişim formu şimdilik cihazın e-posta uygulamasını açacak şekilde ayarlanmıştır.
Domain/hosting'e yüklemeden önce e-posta adresini script.js içindeki mailto bölümüne ekle.

WordPress'e geçilecekse bu tasarım daha sonra WordPress tema yapısına dönüştürülebilir.
